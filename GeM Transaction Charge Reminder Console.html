Step 2 — Confirm Order Details from the Screenshot

Auto-fill mapping: Contract No → Order ID · Department → Buyer Name · Contract Date → Order Date · Transaction Charge computed from the GeM slab rule. Green fields were filled automatically — always verify against the screenshot before adding.

Transaction charge applies only when Pay AMC = Yes. Charge slab: up to ₹10 Lakh → nil · above ₹10 Lakh to ₹10 Crore → 0.30% of order value · above ₹10 Crore → flat ₹3 Lakh.
